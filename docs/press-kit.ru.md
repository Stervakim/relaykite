# RelayKite для Android — факты и материалы для независимого обзора

> Этот документ подготовлен командой проекта. Это **первичный источник**, а не независимый обзор или подтверждение энциклопедической значимости.

## Коротко

**RelayKite** — открытый независимый проект для управления собственным Android через подключённый личный плагин ChatGPT. Команды выполняются агентом на **самом телефоне**, а не на компьютере. При обычной работе после настройки не требуются постоянно включённый ПК, USB, настольный ADB или scrcpy. Проект **не связан с OpenAI официально**.

Репозиторий: https://github.com/kalabuxova1-hash/relaykite

Публичный выпуск: https://github.com/kalabuxova1-hash/relaykite/releases/latest

## Устройство системы

1. Владелец отправляет запрос из ChatGPT через **свой личный плагин**.
2. Частный HTTPS-сервер-посредник принимает разрешённую задачу.
3. Агент на Android сам обращается к серверу и забирает её.
4. Агент исполняет действие локально через Termux и root/Magisk, затем отправляет результат.

**Функция «без ПК» относится к исполнению заданий после настройки.** Для разблокировки загрузчика и первоначального root на некоторых телефонах компьютер может понадобиться. Для работы по-прежнему необходимы интернет, доступный сервер, доступ к плагину ChatGPT и запущенный агент.

## Что реализовано в открытом коде

- Получение состояния телефона и аккумулятора.
- Снимки экрана и чтение дерева UI; действия касания, свайпа, кнопок, запуск приложений.
- Список, чтение и изменение файлов; скачивание по HTTPS; установка одобренных владельцем APK.
- Root-команды на телефоне.
- Автозапуск агента через Magisk, обработка задач и журнал выполнения.
- Локальные записи и архивирование с управляемым бюджетом хранения 5 GiB.
- Разделение прав: отдельные личные учётные данные агента и авторизация плагина.

## Проверка утверждения «работает без компьютера»

Это предлагаемый **план независимой проверки**, а не сообщение о завершённом тесте:

1. Подготовить собственное тестовое Android-устройство с Magisk, Termux и личным закрытым сервером по публичным инструкциям.
2. Подключить личный плагин ChatGPT; проверить принадлежность телефона и root.
3. Выключить компьютер полностью и отключить USB.
4. Отправить безопасные запросы из ChatGPT: статус телефона, запуск тестового приложения, чтение UI и создание временного файла.
5. Повторить после перезагрузки и разблокировки телефона; отдельно проверить работу при гашении экрана, при смене сети и после отключения энергосбережения.
6. Проверить отзыв ключа доступа, чтобы старое соединение перестало исполнять задачи.

Ограничения: публичный архив v0.2.0 проходил тестирование в host/mock-среде и не устанавливался поверх действующей личной установки автора. Подтверждённая автором конфигурация: Redmi Turbo 3 / Android 16 / root. Переносимость на другие устройства ещё требует проверки.
