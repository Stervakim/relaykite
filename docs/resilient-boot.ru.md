# RelayKite — стабильный запуск

## Надёжный запуск 0.2.2 и локальный VLESS

- При сбое или неожиданном завершении Python-агента Magisk-служба
  **перезапускает его с паузой 15 секунд**, не выполняя прежние задания повторно.
  Их идентификаторы и результаты защищены существующим журналом и flock.
- При включении телефона сначала дожидается Android и Python в Termux;
  отключение модуля или удаление маркера enabled прекращает новые задачи.
- Для собственного локального HTTP-прокси добавьте в **приватный**
  `/data/adb/mini-codex/config.json` поле
  `"outbound_proxy": "http://127.0.0.1:17890"` (пример порта).
  Поле необязательно. Допускаются **только 127.0.0.1 и ::1** с явным портом;
  удалённые прокси, пользователь/пароль и URL подписки запрещены. Настройте
  локальный слушатель заранее. Шифрование до личного HTTPS-relay не отключается.
- Маршрутизация VPN, root/Magisk, приложения, приватный сервер и личные
  ключи при установке этого модуля не заменяются.
- **Для старой личной сборки:** текущий `service.sh` хранит proxy в окружении,
  а маркер `enabled` может отсутствовать. Перед обновлением сохраните копии
  конфигурации, модуля, состояния и памяти; перенесите только локальный адрес
  прокси в `outbound_proxy`, проверьте `configure.py --validate` и только
  после этого создайте `enabled` (0600). Не запускайте стандартную замену
  поверх работающего агента, пока независимый доступ и откат не подготовлены.
  Новая служба **не включает себя автоматически** по факту старого config.json.
- ZIP — это Magisk-модуль, не APK; саму карточку ChatGPT обновляют отдельно
  без смены личного App ID. Одна замена файлов не доказывает восстановление связи.

Версия 0.2.2 проверяется офлайновыми тестами. Поведение после полной установки
на других устройствах нужно проверять отдельно.
