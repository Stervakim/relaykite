## Main hook

**Let ChatGPT tap, swipe and run tasks on your devices.**

RelayKite connects ChatGPT to your Android phone and Windows PC through your own private MCP relay. Your AI conversation plans the task. A local worker performs the authorized action and brings the result back.

Android uses an APK with embedded Python/Node. Root/Magisk is needed for privileged and autonomous modes; Termux is optional. After setup, everyday phone control needs no permanently running PC. Windows uses a separate Python/PowerShell worker. Both need internet, a private relay and a supported personal plugin connection.

Project: https://github.com/Stervakim/relaykite

## Longer community introduction

I'm sharing RelayKite, an independent open-source project for carrying out device tasks from a ChatGPT conversation. The Android worker runs on the phone with an embedded Python/Node runtime; Magisk enables privileged modes and Termux is optional. After setup, everyday phone control doesn't need a permanently running PC or desktop ADB. A separate Windows worker supports authorized PowerShell and file operations without a phone.

The connection uses your own authenticated HTTPS MCP relay and personal plugin. ChatGPT supplies the AI decisions; RelayKite supplies the device tools and job handling. It needs internet and a supported account connection. It isn't an offline model or a one-click root installer.

I'd welcome reproducible bug reports, independent testing and English documentation feedback. The README separates requirements, available tools and compatibility limits. Version 0.3.0 includes original on-device Codex CLI; some Mini Codex archive names remain for compatibility.
