## Main hook

**Let ChatGPT tap, swipe and run tasks on your devices.**

RelayKite connects ChatGPT to your Android phone and Windows PC through your own private MCP relay. Your AI conversation plans the task. A local worker performs the authorized action and brings the result back.

Android uses existing root, Magisk and Termux. After setup, everyday phone control needs no permanently running PC. Windows uses a separate Python/PowerShell worker. Both need internet, a private relay and a supported personal plugin connection.

Apps, screen inspection, files and authorized PowerShell tasks, with local workers and open-source code. Android needs existing root/Magisk/Termux; setup and account support are required. Explore the source and try a small, verifiable task.

## Longer community introduction

I'm sharing RelayKite, an independent open-source project for carrying out device tasks from a ChatGPT conversation. The Android worker runs on the phone in Termux with Magisk startup. After setup, everyday phone control doesn't need a permanently running PC or desktop ADB. A separate Windows worker supports authorized PowerShell and file operations without a phone.

The connection uses your own authenticated HTTPS MCP relay and personal plugin. ChatGPT supplies the AI decisions; RelayKite supplies the device tools and job handling. It needs internet and a supported account connection. It isn't an offline model or a one-click root installer.

I'd welcome reproducible bug reports, independent testing and English documentation feedback. The README separates requirements, available tools and compatibility limits. Version 0.2.5 archives retain their old Mini Codex filenames for compatibility.

## Keep every hook supportable

Put requirements beside the claim. Do not use fake popularity, invented benchmarks, “works on every phone,” “unlimited/free ChatGPT,” “fully offline,” “world's first,” or “no setup.” Google Discover advises descriptive headlines and avoiding misleading/exaggerated previews. Strong wording should earn its click by explaining and demonstrating the actual project.
