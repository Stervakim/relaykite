# Discoverability: what is configured and what comes next

RelayKite uses one public name, an English-first README, descriptive installation links, a distinct kite mark, a public HTML introduction and an original architecture/verification guide. The public pages include titles, descriptions, canonical URLs, Open Graph images and a sitemap.

## Search

Primary brand query: **RelayKite**. Supporting phrases should appear naturally where relevant: **ChatGPT Android control**, **Android automation without a PC**, **private MCP relay**, **ChatGPT Windows PowerShell agent**, **self-hosted device automation**. Do not repeat keyword lists in every paragraph.

After GitHub Pages is live, add the URL-prefix property `https://stervakim.github.io/relaykite/` to Google Search Console. Verify ownership using Google's exact HTML file or meta tag, then submit `https://stervakim.github.io/relaykite/sitemap.xml` and inspect the homepage and guide URLs. A verification value must come from the owner's Search Console; none is fabricated here. A project-level robots.txt cannot configure the host-root robots.txt on shared GitHub Pages.

Google chooses crawl timing, result titles and rankings. Renaming alone does not guarantee that spelling corrections disappear. Consistent naming, original content and real references from other sites help establish the entity over time.

## Discover

Google says code repositories can be unsuitable for Discover. An indexed, policy-compliant article is eligible, but eligibility is not a distribution guarantee. Use the public guide as the start of an editorial section; write substantive follow-ups based on real tests.

Useful next articles: a recorded Android task with the computer switched off; a Windows file task with exact grants and results; a compatibility report for another device; a practical explanation of job receipts and recovery. Publish only after collecting evidence. For editorial previews, add a relevant original demonstration image at least 1200 px wide, rather than relying only on a logo/banner. Pages already allow `max-image-preview:large`.

Publish an English demo video showing a complete task and its verified result. Use the same name and canonical project links in the video description and any existing author profile. Ask for independent testing without fabricating endorsements. Outreach and posting to other communities are not performed by this documentation change.

## Measure

Track Search Console impressions, brand queries and clicks after indexing. Measure Discover separately if its report becomes available. Compare GitHub release downloads and real compatibility/bug reports over several weeks; avoid interpreting a single day's traffic as a trend.
