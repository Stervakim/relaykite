Why it exists

Let the conversation do something.

A chat can explain a task. RelayKite connects it to tools that can carry the task out on a device you own.

“Open Settings and read the screen.”Android: app launch, UI inspection, taps and swipes.
“Save this note in my chosen folder.”Device files: read, write and download within configured access.
“List large files in this Windows folder.”Windows: an authorized PowerShell operation with a result in chat.

Illustrative requests; these are not recordings of completed tests.

Choose your starting point

Two devices. Independent workers.

Android, without a running PC

The Python worker runs on your phone in Termux and starts through Magisk. After setup, everyday use needs no USB or desktop ADB.

You need: existing root, Magisk, Termux with Python, internet, your own relay and a supported personal ChatGPT plugin.

Before you install

Clear requirements. Checkable claims.

Is RelayKite a separate AI model?

No. ChatGPT in your active conversation supplies the decisions. RelayKite supplies device tools, workers and a private job relay. It does not run a separate background LLM or train model weights.

Does it work offline or on every Android phone?

It needs ChatGPT, internet and your relay. The documented personal Android configuration is Redmi Turbo 3 / Android 16 / Magisk / Termux. Public bundles have host/mock test coverage; other devices require verification. It does not bypass a secure lock screen.

What does “your private relay” mean?

You deploy and configure your own authenticated HTTPS intermediary. Importing a public plugin card alone does not connect a device. Plugin availability depends on your ChatGPT account. Read the connection guide.

What happened to Codaki Mini Codex?

The project is now called RelayKite. Version 0.2.5 and its legacy archive names remain available. Module IDs, tool names and installation paths are retained for compatibility. Existing private installations are not migrated by a repository rename.

Is it free?

Source and public releases use the MIT license. ChatGPT usage and hosting may have their own costs. RelayKite is independent of OpenAI.
