# Установка на Android

[English](install-android.md) | Русский

Проверьте `SHA256SUMS` и установите подписанный `relaykite-runtime-0.3.0.apk` из [совпадающего релиза](https://github.com/Stervakim/relaykite/releases/tag/v0.3.0). APK содержит Bionic Python/Node и оригинальные Tencent/Graphify. Для основных инструментов нужны телефон, интернет и ваш приватный сервер/плагин; включённый ПК после настройки не нужен.

| Режим | Установка и права |
| --- | --- |
| Без root и Termux | Только APK, обычный UID Android. Память, задания, PTY, файлы в пределах прав приложения. Root/system shell и управление виртуальными экранами других приложений недоступны. |
| Root без Termux | Сначала APK, затем совпадающий Magisk ZIP через уже установленный Magisk. Встроенный runtime и привилегированные инструменты. |
| Root с Termux | Та же установка; необязательные инструменты уже установленного Termux работают под его отдельным UID. |

Выберите режим в APK. Для новой установки импортируйте своё приватное подключение через выбор документа. Поля: `relay_url`, `agent_token`, необязательное `sites_authorization`. Создайте индивидуальные сильные ключи по [инструкции сервера](deploy-private-relay.ru.md). Не передавайте их через чат/аргументы команд; удалите временный файл после импорта. Публичная карточка и APK сами по себе не подключают телефон.

При обновлении сохраните сервер, App ID, ключи, права, память и журнал. Codex получает совпадающий релиз, [INSTALL_WITH_CODEX.md](../magisk/INSTALL_WITH_CODEX.md) и явно выбранный авторизованный телефон/ADB serial. Он не устанавливает root и не разблокирует загрузчик.

Для старой установки на Termux нужна проверенная приватная миграция перед переключением на native runtime. Проверьте квитанцию и исходные ID/версии; не повторяйте завершённую миграцию и не запускайте две копии журнала. [Режимы и восстановление](runtime-modes.md).

Проверьте реальный `phone_status`, режим/UID, исходную память и небольшую разрешённую задачу через подключённый плагин. Установка APK не доказывает связь. Сеть, политика фоновых процессов Android и первое разблокирование после загрузки могут задержать подключение. Недоступные права сообщаются явно, автоматического повышения до root нет.

Необязательная Qwen готовит сводки на сопряжённом ПК. Codex обязан спросить перед установкой модели и дождаться ответа. На телефон модель и OmniRoute не устанавливаются. Основные инструменты и Tencent работают без модели. Фоновые запросы останавливаются при заряде <=20% и возобновляются выше 20%. Любая будущая установка модели на телефон требует отдельного явного вопроса и ответа. [Сводки и удаление](background-summaries.md).

Используйте кнопки режима/остановки APK. Root `stop.sh` отключает контроллер; намеренная остановка сохраняется после перезапуска/обновления. Удаление root-модуля сохраняет `/data/adb/mini-codex` для восстановления памяти/журнала. Перед отключением плагина или удалением всего агента выполните `pc_memory_model_remove` и проверьте квитанцию, пока существующая связь доступна. Прямое отключение плагина не имеет документированного события очистки. Исходную память стирают только по отдельному запросу.


## Автономный Codex на Android (0.3.0)

Это режим того же плагина, а не новое приложение чата. Для новой установки на
rooted ARM64 сначала проверьте `SHA256SUMS`, установите подписанный APK и
совпадающий `mini-codex-magisk-0.3.0.zip` через уже установленный Magisk.
Затем установите `codaki-portable-use-0.1.5-android.zip` как локальный UI backend
по [инструкции Portable](../portable/CODEX_INSTALL.md). Он оставляется остановленным;
после проверки и разрешённого запуска удаляется только его маркер `stopped` и
запускается установленная служба. Без `agent.json` работает root-only IPC:
второй плагин ChatGPT, отдельный сервер и копирование ключей не нужны.

Настройте собственное подключение RelayKite, выберите native root, завершите
необходимую перезагрузку и первое разблокирование. Через подключённый плагин
проверьте `phone_status`, UID 0 и capabilities Portable. Далее `relaykite_dev`
с операцией `capabilities`, затем `install` установит исходный Codex и Git из
зафиксированных SHA-256 upstream-файлов. Дождитесь результата по квитанции;
не повторяйте установку при неизвестном исходе.

Запустите небольшую задачу с выбранной рабочей папкой и `verify_command`.
Проверяйте `status`/`events`; для продолжения, паузы и отмены используйте тот же
`run_id`. Вызовы модели идут через обычный сохранённый чат. Нужны доступный
ChatGPT, разблокированное устройство, сеть и лимит аккаунта. Android root не
изолирован sandbox; ввод изображений модели отключён. После настройки не
требуются постоянно работающий ПК и процесс Termux.

При обновлении сохраняйте конфигурацию, память, журналы, права и намеренную
остановку. При первоначальном переносе старых квитанций сохраните исходный URL
основного relay. Portable не разрешает установку поверх существующей: сначала
завершите сессии, сохраните runtime и приватное состояние и выполните описанное
обновление. Не удаляйте журнал ради повторения неопределённого действия.
[Устройство и управление циклом](DEVELOPMENT.md).
