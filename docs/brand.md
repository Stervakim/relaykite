# RelayKite brand and project identity

Primary name: **RelayKite**. Repository slug: **relaykite**. Pronunciation: **relay + kite** (REE-lay kite). Always use the same CamelCase spelling in prose. Version numbers follow the name and are not part of it.

Tagline: **AI tasks. Your devices.**

One sentence: **RelayKite connects ChatGPT to your Android phone and Windows PC through your own private MCP relay, so a conversation can lead to an action on your device.**

GitHub About description: **Control Android and Windows from ChatGPT. Open-source device agents, your own private MCP relay, phone automation without a running PC, and authorized PowerShell tasks.**

Former name: **Codaki Mini Codex**. Mention it once in migration context. Keep legacy ZIP names, package IDs, installation paths and tool names compatible. The rename does not imply a new runtime version or migration of existing private deployments.

Primary audience: English-speaking Android enthusiasts, self-hosters, MCP developers and Windows automation users. Lead with the task, explain the setup requirements, and distinguish Android from Windows.

Visual identity: graphite `#10171D`, warm paper `#F6F3EB`, signal orange `#F76C3B`, muted ink `#53616A`. The kite symbol represents a task traveling from a chat through a private relay to a device. Use it without an OpenAI logo.
