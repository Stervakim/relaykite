# Наш промпт моста ChatGPT → Codex

В `relaykite-bridge-prompt-example.txt` — настоящий шаблон из публичного
`pc/development/provider.py`, с безопасным учебным инструментом вместо данных
телефона. Секретов, аккаунтов и частной переписки здесь нет.

Чтобы сделать такой мост:

1. Опиши задачу, список разрешённых инструментов и JSON Schema их аргументов.
2. Попроси модель вернуть одно решение в согласованном JSON-формате.
3. Локально проверь имя инструмента, аргументы, права и ID операции; исполни
   разрешённое действие и верни результат модели для следующего шага.
4. Храни журнал: неизвестный результат сначала проверяй, а не выполняй заново.

Пример ответа модели:

```json
{"output":[{"type":"function_call","call_id":"call_status_001","name":"project_status","arguments":{}}]}
```

Исполнитель возвращает результат с тем же `call_id`. После получения результата
модель может закончить:

```json
{"output":[{"type":"message","text":"Проверка проекта завершена: тесты прошли."}]}
```

Текст об успехе допустим только после фактической успешной проверки.
Один промпт не создаёт исполнителя, root-права или доступ к устройству.

На Android наш драйвер добавляет к каждому запросу случайный ID ответа:

```text
RELAYKITE_REPLY_BINDING: <случайные 32 шестнадцатеричных символа>
```

Модель повторяет этот ID в дополнительном корневом поле
`_relaykite_request_id`. Драйвер сверяет его и убирает перед передачей Codex.
Это связывает видимый ответ с текущим запросом, даже если Android скрыл старые
сообщения. ID не является паролем или разрешением на выполнение действий.

Наш шаблон задаёт протокол инструментов и не требует отменять правила модели.
Лимиты аккаунта, вход и настроенные правила исполнения продолжают действовать.
