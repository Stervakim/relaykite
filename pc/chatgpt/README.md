# Карточка Mini Codex PC

Импортируйте codaki-mini-codex-pc-chatgpt-0.2.5.zip. Установка карточки и подключение агента выполняются отдельно. Нет привязки к серверу автора. После собственного deploy соберите приватную карточку: `python chatgpt/package_card.py --app-id YOUR_REGISTERED_APP_ID`. Для обновления сохраните App ID: `python chatgpt/package_card.py --previous-card PATH_TO_OLD_CONNECTED_CARD`. Сборщик сохраняет приватный результат в .private/chatgpt; никогда не публикуйте его.

Новая версия → ZIP GPT → обновление существующего плагина с сохранением связей, прав, ключей и журнала. Если клиент требует ручного импорта, GPT подготовит файл и сообщит этот шаг. См. INSTALL_WITH_CODEX.md.
