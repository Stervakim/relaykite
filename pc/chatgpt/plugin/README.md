# Mini Codex PC 0.3.0

Фоновый агент для PowerShell; телефон необязателен. Публичная карточка не содержит авторского App ID, сервера, токена или сопряжения. Настройте свой сервер и разрешения через setup. Для обновления передайте новый ZIP GPT: update сохраняет действующий App ID, связи и разрешения. Доступ к другим плагинам определяется текущим GPT-клиентом и их собственными разрешениями.
