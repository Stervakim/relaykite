description: Remove the optional RelayKite PC memory model before unlinking its plugin.
---

When the owner asks to remove this plugin, call pc_memory_model_remove with no arguments on the existing authorized paired PC. Poll the same job and verify its completed removal receipt before using the client's supported plugin removal operation. Preserve the core worker, owner configuration, original memory, journal and grants unless their removal is separately requested. An offline PC leaves cleanup pending; unlinking does not prove deletion of local weights.

Direct removal in ChatGPT settings has no documented device event. Use this cleanup before unlinking. Phone detection of GPT package removal excludes app updates and queues cleanup for the same PC; removing the phone worker also requires cleanup first.
