# Установка / обновление Mini Codex PC 0.2.4 через Codex

1. Проверьте источник GitHub Releases и SHA256SUMS. Безопасно распакуйте ZIP: запретите абсолютные пути, `..`, ссылки и выход за выбранный каталог. Установите файлы в устойчивую папку владельца, а не временный каталог загрузки.
2. Проверьте Windows, Python 3.14+ (`python`/`pythonw`), PowerShell и интернет. Не устанавливайте root/ADB/Magisk на ПК. Телефон не требуется. Не запускайте агент с повышением прав.
3. Используйте существующий сервер Mini Codex владельца либо создайте собственный приватный Sites MCP-сервер из вложенного `relay/`. Не используйте авторский App ID или сервер. Обновление существующего сервера требует применения новой миграции `drizzle/0001_hesitant_raza.sql` через штатный deploy/migration workflow Sites, с сохранением таблиц телефона и секретов. На новом сервере применяются обе миграции. Заголовки `oai-authenticated-user-*` доверены только защищённому управляемому хостингу: открытый сервер с пользовательскими заголовками недопустим.
4. Подключите сервер в ChatGPT и импортируйте карточку из `chatgpt/`. Если поддерживаемый клиент требует заполненный App reference, соберите приватную карточку: `python chatgpt/package_card.py --app-id YOUR_REGISTERED_APP_ID`. Она сохраняется в `.private/chatgpt/`; не публикуйте её. Импорт не выполняет сопряжение автоматически.
5. В плагине вызовите `mini_pc_invite` с почтой ChatGPT владельца ПК. Для ПК без телефона пригласите свой аккаунт, `phone_access=false`. Для доступа ПК к телефону владелец телефона явно задаёт `phone_access=true`. Приглашение действует 10 минут, одноразовое; передайте код владельцу самостоятельно. Для другого аккаунта заранее настройте разрешённый доступ к Site/плагину; email не обходит приватность.
6. На конкретном ПК владелец выбирает права и папки. Никакие права не включайте за него. Пример после явного согласия владельца на PowerShell:

```powershell
python mini_codex_pc.py pair --relay https://YOUR_RELAY_HOST --label "Мой ПК" --root "D:\Projects" --allow terminal --allow files_read --allow files_write
```

Без `--allow` доступен только статус. Терминал и делегирование Codex дают широкий доступ с правами владельца, а не изоляцию в `--root`. Команда запросит `ALLOW`, код приглашения и при необходимости авторизацию хостинга без вывода секретов. Конкретные права подтверждает владелец ПК, а не удалённая модель.

7. Программа сохраняет черновик, показывает отпечаток и ссылку `/bridge?id=...`. Откройте ссылку на этом ПК, войдите в указанный ChatGPT-аккаунт, сравните отпечаток и подтвердите запрошенные права. Не подтверждайте другой или неожиданный ПК. Затем:

```powershell
python mini_codex_pc.py activate --connection CONNECTION_ID
./install-background.ps1
```

Фоновое задание выполняется через `pythonw.exe` без окна в интерактивной сессии владельца и возобновляется при входе в Windows. ПК должен быть включён, подключён к интернету и не спать; после выхода владельца из Windows выполнение недоступно. `start` включает приостановленный агент, `stop` запрещает следующие команды.

8. Проверьте `mini_connections`: нужный ПК должен стать `active` и `online`, причём `last_seen` должен обновляться самим фоновым агентом. Запущенное задание Планировщика само по себе не доказывает связь. Проверьте `mini_pc_call` с `pc_status`, затем безопасную команду `Get-Date` с уникальным `request_id`; без `cwd` используется первая разрешённая папка. Получите результат через `mini_pc_result`. Если файловые операции установщика выполняются в изолированном окружении клиента, отдельно проверьте, что реальное фоновое задание владельца видит установленные файлы и сохранённое подключение. Не передавайте ключи в аргументах команд, журналах или общедоступных файлах. При неизвестном исходе проверяйте состояние, а не повторяйте команду. Доступные плагины Computer Use/Sites проверяются в текущем GPT-клиенте отдельно; агент не объявляет их установленными автоматически.
9. При необходимости обычного Codex: установите/авторизуйте Codex CLI штатно, не извлекайте его токены. Сопрягайте ПК с явно разрешённым `--allow codex`. Настройте локальный argv через `configure --connection ID --codex-launcher JSON_ARGV`. На Windows `.cmd` нельзя безопасно подставлять как оболочку: используйте прямой бинарный launcher или `node.exe` и установленный JS launcher Codex как отдельные элементы JSON массива. `pc_codex` использует `codex exec`, sandbox `workspace-write` и собственные правила Codex; подтверждения могут потребовать локального участия.
10. ПК → телефон: `phone-call --connection ID --tool phone_status --arguments '{}' --request-id UNIQUE_ID`. Для обычного Codex можно подключить локальный stdio MCP: Python + абсолютный путь `mini_codex_pc.py mcp --connection ID`. Для каждого телефона выбирается его ID; можно добавить любое количество связей. Телефон → ПК: инструменты `mini_pc_call` в GPT либо явный `agent/pc_peer.py` на телефоне, использующий уже существующие приватные настройки. Постоянное соединение устройств друг с другом не нужно.

## Обновление новым ZIP

Новый релиз → файл GPT → «Обнови Mini Codex, сохрани связи, ключи, права и журнал».

Проверьте SHA256SUMS и версии. Остановите ровно фоновое задание Mini Codex через `Stop-ScheduledTask -TaskName 'Codaki Mini Codex PC'`, дождитесь его завершения, сохраните резервную копию исходников и замените только публичные файлы. Обновите сервер с сохранением D1/секретов, когда релиз требует миграции. Приватная конфигурация `%LOCALAPPDATA%/CodakiMiniCodex/` остаётся на месте: не удаляйте `config.json`, `journal.sqlite` и резервные копии. Перезапуск переводит прерванное задание в uncertain и не повторяет его.

Обновите карточку через `python chatgpt/package_card.py --previous-card PATH_TO_PREVIOUS_CONNECTED_CARD`. Сохраните App ID и личные подключения. Если нужной операции импорта в клиенте нет, подготовьте файл для ручного обновления и сообщите, что оно ещё не установлено. Возобновите прежнее задание через `Start-ScheduledTask`, проверьте статус и round trip. Новые права требуют отдельного подтверждения. Установка/обновление только карточки не меняет агент, разрешения или настройки телефона.
