# RelayKite PC — 0.3.0

Фоновый агент Windows без окна. GPT → личный HTTPS MCP-сервер → агент → PowerShell → результат GPT. Python 3.14+, PowerShell, интернет и собственный сервер; телефон не нужен. Агент открывает только исходящие HTTPS-запросы и запускается с правами обычного Windows-пользователя.

## Установка через Codex

Скачайте `mini-codex-pc-0.3.0.zip`, `codaki-mini-codex-pc-chatgpt-0.3.0.zip` и `SHA256SUMS` из [релиза](https://github.com/Stervakim/relaykite/releases/tag/v0.3.0). Карточка есть и внутри установщика под `chatgpt/`.

Передайте файлы Codex:

> Установи Mini Codex PC 0.3.0 из этого ZIP. Проверь SHA256SUMS и прочитай INSTALL_WITH_CODEX.md. Подключи мой личный сервер и карточку GPT, согласуй папки и доступ к PowerShell, сохрани существующие связи. Настрой фоновый запуск без окна. Проверь pc_status и безопасную команду PowerShell. Для Computer Use и Sites используй доступные плагины с их собственными разрешениями.

Подробный порядок: [INSTALL_WITH_CODEX.md](INSTALL_WITH_CODEX.md). Импорт публичной карточки не подключает сервер автора, не регистрирует ПК и не даёт доступ к терминалу.

## Другие плагины

GPT может использовать Mini Codex вместе с Computer Use, Sites, GitHub и другими доступными плагинами в одном задании. Например: открыть приложение через Computer Use, обработать файл через `pc_terminal`, создать сайт через Sites, проверить результат.

**Вызовы других плагинов делает GPT через инструменты текущего клиента.** Агент PowerShell не получает их скрытые инструменты, авторизацию и сессии автоматически. Перед действием GPT проверяет, что плагин доступен, разрешён владельцем и работает именно с нужным ПК/аккаунтом. Локальный Computer Use в чате, открытом на другом ПК, не управляет сопряжённым компьютером. Если подходящего доступа нет, GPT сообщает об этом и использует доступные терминальные операции. `pc_status` описывает этот режим, а не выдаёт предположения за установленные плагины.

Обычный Codex подключается отдельно через установленный владельцем Codex CLI (`pc_codex`). Это отдельный запуск Codex, а не управление произвольным открытым чатом desktop-приложения. Его профиль, авторизация, доступные плагины, sandbox и правила подтверждений остаются в силе. Mini Codex не читает и не копирует токены ChatGPT/Codex.

## Связи с телефонами и ПК

Число сохранённых связей программно не ограничено. Телефон может связаться с множеством ПК; ПК — с множеством телефонов, каждый через личный сервер соответствующего телефона. Для каждого сопряжения — отдельные учётные данные, подтверждение, разрешения и отзыв. Практический масштаб зависит от ресурсов и квот хостинга. Ограничения размера сообщений и очереди на конкретное устройство сохраняются.

Почта ChatGPT адресует приглашение. Доступ требует входа в ChatGPT с этой почтой, сравнения отпечатка и подтверждения на ПК. Email сам по себе не даёт доступ; программа не отправляет письма. Для другого аккаунта владелец сервера должен разрешить доступ к Site/плагину через поддерживаемое управление доступом. Сопряжение не обходит ограничения приватного хостинга.

`mini_connections` показывает email, имя, ID и состояние каждой связи. ID различает несколько устройств с одной почтой. Связи сохраняются на сервере и в приватной конфигурации ПК. Телефон и ПК работают самостоятельно; постоянное соединение друг с другом не требуется. Команда на второе устройство выполняется только по запросу, когда оно доступно. Выключенный телефон не мешает ПК, выключенный ПК не мешает телефону.

## Обновление через GPT

**Вышла новая версия → скачали ZIP → передали GPT → попросили обновить плагин и агент.**

> Обнови Mini Codex из нового ZIP. Сохрани все сопряжения, App ID, ключи, разрешения, память и журнал. Проверь SHA256SUMS из официального релиза и версию, обнови существующую карточку и агент и проверь соединение. Не включай новые права автоматически.

Проверяется SHA256 из `SHA256SUMS` (это контрольная сумма, а не криптографическая подпись). Карточка обновляется с прежним App ID через `chatgpt/package_card.py --previous-card ...`. Если клиент требует ручной импорт, GPT подготовит ZIP и укажет этот шаг. Конфигурация и журнал находятся отдельно от файлов установщика; их не удаляют. Задание с неизвестным исходом после перезапуска не выполняется повторно.

## Остановка и отзыв

`python mini_codex_pc.py stop` запрещает следующие задания. Уже начатая команда может завершиться; её результат и состояние проверяются отдельно. `start` снимает этот запрет. `revoke --connection ID` отключает связь локально сразу и отзывает её на сервере при доступном интернете. `mini_disconnect` отзывает связь с серверной стороны. Удаление фонового задания: `./install-background.ps1 -Remove`; оно сохраняет конфигурацию и журнал.

Файловые инструменты ограничены выбранными папками, отвергают ссылки/junction и сохраняют резервную копию небольшого файла перед перезаписью. Разрешение `terminal` предоставляет доступ с правами Windows-пользователя: папки файловых инструментов не являются sandbox PowerShell. `codex` разрешает делегирование задач Codex с его собственными политиками. Новые сопряжения по умолчанию дают только статус.

Windows maintenance: Mini PC now exposes twelve pc_use_* operations through the existing Portable engine and owner-local RPC, under the existing terminal grant. Native images and both receipt layers are preserved; queued PC jobs can be cancelled. Requires Portable0.1.3 with --local-ipc-windows. Window leases share a desktop; physical input remains serialized.

For PC UI follow chatgpt/plugin/skills/using-codaki-pc-use/SKILL.md. Keep the existing PC connection, grants, credentials and journal. Do not register a second Portable agent.
