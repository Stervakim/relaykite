# История изменений

## 0.1.5 — проверка состояния перед вводом

Входит в RelayKite 0.3.0. Старое наблюдение больше не допускает повторное
нажатие, если изменились checked, selected, доступные actions или scrollable.
Квитанции, принадлежащие сессии экраны и запрет повтора uncertain сохранены.
Протокол IPC совместим с 0.1.4; данные владельца не являются частью пакета.

## 0.1.4 — несколько Android-экранов
Android0.1.4: до трёх отдельных виртуальных дисплеев, независимые lease и observations, общий инспектор и последовательный ввод. На Redmi Android17 проверены два дисплея (Настройки/Часы), собственные UI и PNG, batch/repeat, остановка одного без второго и полное освобождение. Java-исходники и сборщик ядра включены. Mini использует тот же root-only IPC; публичный agent поддерживает --local-ipc. Несколько экранов используют общие данные приложений; одна activity может переноситься между ними. Windows остаётся с общим desktop и до8 оконными сессиями.



## 0.1.3 — Windows batch и локальный мост Mini Codex
- Windows batch: 1–12 последовательных шагов в выбранной оконной сессии, без повторного ввода, с остановкой при ошибке/uncertain и сохранением применённых шагов.
- После аварии сохраняются checkpoint родительского запроса и ID незавершённого шага; reconciliation не повторяет действие.
- Опциональный --local-ipc-windows использует тот же engine/UIA-поток и журнал. Локальный секрет хранится с ACL владельца/SYSTEM; Mini connection изолирует ID результатов и владение оконными сессиями.
- MCP/облачный интерфейс возвращают последнее вложенное изображение и статус stopped. Общий Windows desktop и сериализация физического ввода сохранены.

## 0.1.2b — 2026-10-11
- Windows: после GUI-действия и запуска программы другие открытые сеансы требуют повторного observe; ввод со старым observation возвращает STALE. Протестированы два настоящих окна (Brave и Блокнот) и регрессии.
- Android: исправлено отображение версии через __version__.
- Android и полный ZIP собираются из проверенных исходников в GitHub Actions, с новыми SHA-256, без приватных файлов. Старые ZIP 0.1.2 не заменяются.
- Параллельные сеансы до 8, последовательный физический ввод, привязки, настройки и работа приложений не изменены.

## 0.1.2 — 2026-10-11
- Hotfix 0.1.2: Windows-действия и запуск приложений сбрасывают старые наблюдения в других сеансах; добавлены проверки STALE и сохранён последовательный ввод. Android теперь сообщает фактическую версию 0.1.2 из пакета.
- Добавлены дополнительные регрессионные проверки Windows: безопасный повтор остановки сеанса, сериализация ввода из двух потоков и освобождение закрытого окна без влияния на остальные; 10/10 тестов WindowsSessions прошли на Windows.
- Windows cloud enrollment: WINDOWS_DEVICE_ID и отдельный секрет WINDOWS_DEVICE_TOKEN; сохранены существующие DEVICE_TOKENS.
- До восьми сеансов разных Windows-окон, отдельные наблюдения и lease, общий журнал и сериализованный ввод.
- Защита от повторного занятия окна и использования чужого observation.
- Исправлены fingerprint и screenshot-проверки Windows-ввода.
- Windows-установщик, автозапуск, исходники Sites relay и инструкция Codex.
- Полный ZIP, Android ZIP, SHA-256 manifest; секреты и runtime-состояние исключены.
