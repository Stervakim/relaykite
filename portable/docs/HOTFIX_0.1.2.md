# Portable Use 0.1.2 — исправления Windows и Android

**Обновление:** исправленные исходники выпускаются отдельной версией [0.1.2b](https://github.com/kalabuxova1-hash/codaki-portable-use/releases/tag/v0.1.2b). Старые ZIP 0.1.2 сохранены без изменений; для установки исправлений берите архивы 0.1.2b.

Это **обновление внутри версии 0.1.2**, без повышения до 0.1.3.

## Исправления исходников в main

- `src/portable/windows_sessions.py`: после `action` и `launch` наблюдения других Windows-сеансов сбрасываются. Сеансы и приложения остаются открытыми. Новое `use_observe` обязательно перед следующим действием в другом окне. Сброс происходит и при неопределённом/отклонённом вводе.
- `src/portable/android.py`: поле версии в capabilities берётся из `portable.__version__`; установленный Android 0.1.2 корректно сообщает `0.1.2`.
- `tests/test_windows_sessions.py`: тесты устаревших наблюдений, последовательного ввода, отказов и запуска приложений.

Проверено на Windows: 11 синтетических тестов, два реальных окна (Brave и Блокнот), действие фокуса и ожидаемый ответ `STALE` для старого наблюдения в другом окне. Обе GUI-сессии затем закрыты без закрытия пользовательских приложений.

## Внимание: готовые ZIP релиза

**Пока исходники main новее, чем опубликованные ZIP `dist/codaki-portable-use-0.1.2-*.zip` и вложения релиза v0.1.2.** Исходники изменены, но загрузка пересобранных бинарных архивов через доступное соединение была заблокирована. Не считать старые ZIP содержащими хотфикс.

Чтобы получить исправленную Windows-версию, установите соответствующие файлы из текущего `main` поверх существующего runtime **только после остановки правильного Windows-агента**. Сохраните копии старых файлов, настройки `agent-windows.json`, `windows-agent-state`, виртуальное окружение `.venv` и исходные привязки; после запуска проверьте online, два разных сеанса, `observe` и `STALE`.

На уже работающем Android не запускайте старый ZIP как повторную Magisk-установку. Сохраните `/data/adb/codaki-portable-use` и `module.prop`, обновите runtime с сохранением данных и перезапустите только Portable Use agent. Не затрагивайте Mini Codex, Android Use, root/Magisk, VPN/VLESS или другие приложения.

Для повторной сборки из исходников используйте `scripts/build_module.py` и `scripts/build_release.py`; контрольные суммы нужно **пересчитать для новых ZIP**. Старый `dist/SHA256SUMS` относится только к прежним файлам.

Без подтверждения `use_devices` и проверенных GUI-операций не считайте обновление успешным.
