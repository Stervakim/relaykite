# RelayKite: личный relay телефона

[English](README.md) | Русский

Этот шаблон исходников соединяет приватный ChatGPT-плагин одного владельца с одним Android-телефоном с root. У каждого развёртывания свои приватные Site, база данных, плагин и ключ телефона. Это не общий публичный сервер управления.

Следуйте [инструкции развёртывания собственного приватного relay](../docs/deploy-private-relay.ru.md). Hosting manifest шаблона намеренно не содержит ID проекта или ключей. Развёртывайте из своей приватной копии; оставляйте публичный шаблон без личной конфигурации.

Для локальных проверок исходников нужен Node.js 22.13 или новее:

```sh
npm ci
node --test tests/*.test.mjs
npm run build
```

Сборка создаёт Worker для Cloudflare. При локальной разработке используется тестовая identity для входа; она не устанавливает владельца в production. Размещённый Site должен оставаться приватным, а Sites должен обеспечивать авторизацию на своей границе.

Исходники сохраняют закрепление первого авторизованного владельца, проверку токена телефонных endpoints, ограниченную очередь заданий, атомарное получение задания, дедупликацию запросов и обработку неопределённых результатов. Перед повторением разрушительной операции проверяйте просроченное задание или задание с неопределённым результатом.

Страница relay открывается на английском по умолчанию. Ссылка **Русский** переключает её на русский; **English** возвращает английский.
