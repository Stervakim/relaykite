# RelayKite — ИИ выполняет задачи на ваших устройствах

![RelayKite — AI tasks. Your devices.](docs/assets/relaykite-cover.png)

[English](README.md) · [Сайт](https://stervakim.github.io/relaykite/) · [Скачать 0.3.0](https://github.com/Stervakim/relaykite/releases/tag/v0.3.0)

**RelayKite — открытый проект для управления своим Android и Windows из ChatGPT через личный приватный MCP-сервер.** ИИ планирует задачу в чате, а агент на устройстве выполняет разрешённые действия и возвращает результат.

Раньше проект назывался **Codaki Mini Codex**. Выпуск 0.3.0 добавляет автономный оригинальный Codex к существующему агенту устройств. Имена ZIP, модулей, инструментов и технические пути сохранены для совместимости с существующими установками.

## Для чего он нужен

- Проверить состояние телефона, открыть приложение, прочитать экран, нажать или сделать свайп.
- Читать, сохранять и скачивать файлы; устанавливать одобренные APK.
- Диагностировать службы и повторно использовать сохранённые решения.
- Выполнить разрешённую команду PowerShell или работу с файлами на своём Windows-ПК.

Примеры: «Проверь заряд телефона», «Открой настройки и прочитай экран», «Сохрани эту заметку в выбранной папке», «Покажи крупные файлы в этой папке Windows». Это примеры запросов, а не запись проведённого теста.

## Android и Windows работают самостоятельно

**Android:** подписанный APK содержит Bionic Python/Node. Есть обычный режим без root/Termux, root со встроенным runtime и root с необязательными инструментами Termux. После настройки постоянно включённый ПК, USB и настольный ADB не нужны. Нужны интернет, личный HTTPS-сервер и подключение плагина. Для привилегированных режимов нужен уже установленный Magisk.

**Windows:** отдельный фоновый агент выполняет PowerShell и файловые операции в рамках настроенного доступа. Нужны Python 3.14+, PowerShell, интернет и личный сервер. Телефон ему не требуется.

Основной ИИ работает в ChatGPT. Необязательная локальная Qwen на сопряжённом ПК готовит предложенные сводки памяти в фоне, без прав управления телефоном. Установка модели требует явного выбора. Запросы телефона приостанавливаются при заряде <=20%; без ПК основные инструменты и память работают самостоятельно.

## Установка

1. Скачайте подходящий ZIP и `SHA256SUMS` из [релиза 0.3.0](https://github.com/Stervakim/relaykite/releases/tag/v0.3.0).
2. Проверьте SHA-256 и требования устройства.
3. Следуйте [инструкции Android](docs/install-android.ru.md) или [инструкции Windows](pc/README.md): настройте собственный приватный сервер и плагин.
4. Проверьте статус устройства и небольшую безопасную задачу.

Android: `relaykite-runtime-0.3.0.apk`, для root-режимов также `mini-codex-magisk-0.3.0.zip`. Windows: `mini-codex-pc-0.3.0.zip`. Карточки ChatGPT поставляются отдельно и внутри установщиков. Импорт карточки сам по себе не подключает устройство.

> Установи RelayKite 0.3.0 из этого ZIP на выбранное мной устройство. Прочитай INSTALL_WITH_CODEX.md, проверь SHA256SUMS и требования, настрой мой приватный сервер и проверь связь. Используй доступные инструменты устройства. При обновлении сохрани ключи, сопряжения, права, память и журнал.

**Статус исходников после 0.3.0.** В ветке `main` для следующей сборки
закреплён официальный Codex CLI **0.165.0** с проверенными SHA-256 архива и
исполняемого файла. На Android проверены `--version` и `app-server --help`.
Установленный у автора Android-бинарник 0.165.0 отличается от публичного
Linux-musl бинарника, поэтому полная эквивалентность ещё не доказана.
Скачиваемый релиз **v0.3.0 всё ещё содержит Codex 0.154.0**: новая версия
появится в установщике только после отдельной сборки, подписи и публикации.
Нельзя смешивать APK и ZIP разных выпусков.

В 0.3.0 оригинальный Codex 0.154.0 работает на телефоне: патчи, shell, Git, последовательные инструменты, контрольные точки и штатное сжатие контекста. Устойчивый цикл продолжает задачу после завершения внешнего ответа ChatGPT; доступны пауза, продолжение и отмена. Модель вызывается через обычный сохранённый чат, без API-ключа и временных чатов. Нужны установленный ChatGPT, разблокированное устройство, интернет и доступный лимит аккаунта.

Интерфейсом остаётся плагин **RelayKite · Codex Android**; ПК — **RelayKite · Codex**, с общей синей иконкой. Для автономного Android нужны уже установленный root/Magisk, подписанный runtime и Portable-компонент. Плагины ChatGPT не превращаются автоматически в инструменты Codex: доступны совместимые skills и настроенные MCP-серверы. Android root не изолирован sandbox; ввод изображений в телефонную модель пока отключён. [Устройство цикла](docs/DEVELOPMENT.md) · [Проверки и ограничения](docs/development-progress.md).

Проверенная конфигурация 0.3.0: Redmi Turbo 3 / Android 17 / Magisk, встроенные Python/Node без runtime Termux. Кроме host/mock-тестов проверены реальные патчи, shell, Git, сжатие контекста и Android MCP; другие устройства требуют отдельной проверки. Проект не обещает полностью офлайн-ИИ, обход блокировки и одинаковую поддержку всех устройств.

RelayKite — независимый проект под [MIT](LICENSE), не официальный продукт OpenAI. Исходники и выпуски бесплатны; у ChatGPT и хостинга могут быть собственные расходы. [Поддержать разработку](https://boosty.to/mini_codexandroid).
